# Archive

Historical and handoff-oriented documentation lives under `docs/archive/`.

Use the active flat docs first:

- `docs/README.md`
- `docs/GETTING_STARTED.md`
- `docs/OPERATIONS.md`
- `docs/TESTING.md`
- `docs/ARCHITECTURE.md`
- `docs/DEVELOPMENT.md`
- `docs/REFERENCE.md`

Archived docs are kept for context and migration history. They may include:

- pre-refactor structure
- superseded architecture wording
- older runtime and test layout assumptions
- handoff-only notes
